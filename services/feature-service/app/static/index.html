How Features Are Built

New Feature Built From Formula / Meaning
total_bytes sbytes, dbytes sbytes + dbytes
total_packets spkts, dpkts spkts + dpkts
byte_ratio_src_dst sbytes, dbytes sbytes / (dbytes + 1)
packet_ratio_src_dst spkts, dpkts spkts / (dpkts + 1)
bytes_per_packet sbytes, dbytes, spkts, dpkts Total bytes divided by total packets
proto_events_last_60s proto, event timestamp Number of events with the same protocol in the last 60 seconds
service_events_last_60s service, event timestamp Number of events with the same service in the last 60 seconds
avg_total_bytes_last_60s sbytes, dbytes, event timestamp Average total_bytes across the last 60 seconds

attack_cat and label are intentionally excluded from feature generation to avoid target leakage.
